# _Triangle Tracker_

#### By _Calen Kempton_

#### _This is a website that shows whether or not the number of lengths the user put in is a triangle_
---
## _Technologies used_
* HTML
* CSS
* VSCode
* Git
* Bootstrap
* Javascript
---
## _Description_

_This is a practice website where if the user put in three lengths of any number they will get a result saying whether the lengths make a equilateral, isosceles, or scalene triangle or not._
---
## _Setup/Installation Requirements_
* Go to Github repository.
* Click on code.
* Copy link.
* Use git clone command.
* Open in VSCode.
